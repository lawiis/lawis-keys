## ✨ Features

- 🔊 **Realistic Sound Packs**: Cherry MX, Alpaca, Creamy, Tactile, Typewriter, hingga clicky custom sound packs.
- 🖱️ **Mouse Click Sounds**: Suara klik mouse sinkron dengan volume terpisah.
- 🎨 **Modern UI & Themes**:
  - **Dark Obsidian**: Minimalis, gelap, elegan, dan bersih.
  - **Liquid Glass**: Efek kaca transparan (glassmorphism) dengan luminous ambient glow.
  - **Cyber Glow**: Tampilan neon cyan futuristik bertema cyberpunk.
- ❄️ **Interactive Snowflakes**: Efek butiran salju melayang yang bereaksi goyang tertiup angin setiap tombol diketik.
- ⭐ **Favorites & 🕒 Recently Used**: Simpan sound favorit dengan 1 klik bintang, dan akses riwayat sound yang baru saja dipakai.
- ⌨️ **Interactive 3D Keyboard**: Visualisasi keyboard F75 3D responsif tanpa membebani GPU/RAM.
- 🎮 **Discord Rich Presence (RPC)**: Menampilkan sound pack keyboard yang sedang aktif di profil Discord kamu.
- 📌 **System Tray Integration**: Opsi sembunyikan atau tutup ke system tray di latar belakang.
- ⚡ **Zero-Lag Engine**: Dirancang sangat ringan (~0% CPU saat idle) tanpa layout reflow berat.

## 🛠️ Developer Setup

Jika kamu ingin menjalankan atau memodifikasi dari source code:

1. **Clone repository**:
   ```bash
   git clone https://github.com/lawiis/lawis-keys.git
   cd lawis-keys
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Jalankan aplikasi (Development)**:
   ```bash
   npx electron .
   ```
