## ✨ Features

- 🔊 **Authentic Sound Packs**: Cherry MX, Alpaca, Creamy, Tactile, Vintage Typewriter, Clicky, Gaming switches, and fun meme sound packs.
- 🖱️ **Synchronized Mouse Click Sounds**: Satisfying mouse clicks with independent volume control.
- 🎨 **Modern Themes & Glassmorphism**:
  - **Dark Obsidian**: Sleek, clean, and minimalist dark aesthetic.
  - **Liquid Glass**: Translucent frosted glass effect with luminous ambient glow.
  - **Cyber Glow**: Futuristic cyberpunk styling with neon cyan highlights.
- ❄️ **Interactive Snowflakes FX**: Gentle falling snow particles that drift and flutter dynamically with your typing rhythm.
- ⭐ **Favorites & 🕒 Recently Used**: Quick 1-click star bookmarking and automated history for both keyboard and mouse sounds.
- ⌨️ **Interactive 3D Keyboard**: Real-time responsive F75 mechanical keyboard stage rendered with zero-lag CSS transforms.
- 🎮 **Discord Rich Presence (RPC)**: Automatically displays your active keyboard sound pack on your Discord profile.
- 📌 **System Tray Integration**: Background running support with "Hide to Tray" and "Close to Tray" settings.
- ⚡ **High Performance & Zero-Lag**: Engineered for near 0% idle CPU and minimal RAM footprint.

## 🛠️ Developer Setup

If you want to run or build the application from source code:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/lawiis/lawis-keys.git
   cd lawis-keys
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development mode**:
   ```bash
   npx electron .
   ```
